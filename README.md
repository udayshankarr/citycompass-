## 📖 Project Overview
CityCompass Karnataka is a mobile-first responsive travel hub for tourists visiting Karnataka.  
It provides destination hubs, travel circuits, arrival guides, and a Kannada phrasebook.

## 🚀 Features
- Destination hubs: Bengaluru, Mysuru, Hampi, Coorg, Gokarna
- Tabs: Getting Around, Eat, Stay, Explore, Essentials
- Arrival Guide for airport-to-hotel navigation
- Circuits: Heritage, Coastal, Hills
- Trip planner with itineraries
- Kannada mini-phrasebook (tap-to-hear)
- Save-to-my-trip sharing

## 🛠 Tech Stack
- React + Vite
- Leaflet + OpenStreetMap
- Geoapify / Overpass APIs
- Hosting: Vercel / Netlify
- Multilingual support (English, Kannada, Hindi)
- Dark mode

## 📊 Data Strategy
- Transport curated in JSON, verified against official sites
- Places from OpenStreetMap
- Attractions from Karnataka Tourism & KSTDC

## 🎤 Pitch Line
*"Tourists in Karnataka juggle five apps and don’t speak Kannada.  
CityCompass makes getting around, eating, and staying simple in one place."*
